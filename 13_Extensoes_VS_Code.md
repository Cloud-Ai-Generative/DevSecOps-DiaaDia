### Como instalar a extensão C\# no VS Code:

1.  Abra o VS Code.
2.  Vá para a aba **Extensions** (ou pressione `Ctrl+Shift+X`).
3.  No campo de busca, digite **C\#**.
4.  Clique em **Install** na extensão publicada pela Microsoft.

-----
