Como Gerar Token de Acesso Pessoal no GitHub
Passo a Passo para Criar o Token
1. Acessar as Configurações do GitHub
Entre na sua conta do GitHub

Clique na sua foto de perfil no canto superior direito

Selecione Settings

2. Navegar até a Seção de Tokens
No menu lateral esquerdo, clique em "Developer settings"

Selecione "Personal access tokens"

Clique em "Tokens (classic)"

Botão "Generate new token" → "Generate new token (classic)"
